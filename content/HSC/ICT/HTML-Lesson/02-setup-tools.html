🛠️ সেটআপ ও টুলস

কোড লেখার জন্য প্রয়োজনীয় টুলস, প্রথম HTML ফাইল তৈরি, ব্রাউজারে চালানো এবং দরকারি শর্টকাট — সবকিছু এখানে।

💻 কোড এডিটর নির্বাচন

HTML লেখার জন্য যেকোনো টেক্সট এডিটরই যথেষ্ট, তবে ভালো এডিটর কাজ সহজ করে দেয়। নিচের অপশনগুলো থেকে একটি বেছে নিন:

🟦

Visual Studio Code

সবচেয়ে জনপ্রিয়

ফ্রি, শক্তিশালী, অসংখ্য এক্সটেনশন। শিক্ষার্থীদের জন্য সেরা।

🟩

Notepad++

হালকা

Windows-এর জন্য হালকা এডিটর। পুরনো কম্পিউটারে দ্রুত চলে।

🟨

Sublime Text

দ্রুত

অত্যন্ত দ্রুত ও মসৃণ। তবে কিছুদিন পর লাইসেন্স চায়।

📝

Notepad / TextEdit

বেসিক

OS-এ আগে থেকেই থাকে। একেবারে শুরুর জন্য যথেষ্ট।

💡 সুপারিশ: শিক্ষার্থীদের জন্য Visual Studio Code (VS Code) সবচেয়ে ভালো। এটি ফ্রি, বাংলা ইন্টারফেস সাপোর্ট করে এবং লাইভ প্রিভিউ দেওয়া যায়।

📥 VS Code ইনস্টল ও সেটআপ

১

ডাউনলোড করুন

ব্রাউজারে code.visualstudio.com এ যান এবং আপনার অপারেটিং সিস্টেম (Windows/Mac/Linux) অনুযায়ী ডাউনলোড করুন।

২

ইনস্টল করুন

ডাউনলোড করা ফাইলটি ওপেন করে Next → Next → Install ক্লিক করুন।

৩

প্রয়োজনীয় এক্সটেনশন ইনস্টল করুন

বাম পাশের Extensions আইকনে ক্লিক করে সার্চ করুন:
• Live Server — ফাইল সেভ করলেই ব্রাউজারে অটো রিফ্রেশ
• Prettier — কোড সুন্দরভাবে সাজায়
• Auto Rename Tag — ট্যাগ অটো রিনেম করে

৪

নতুন ফোল্ডার তৈরি করুন

যেমন ডেস্কটপে html-lesson নামে একটি ফোল্ডার তৈরি করুন। এই ফোল্ডারেই সব ফাইল রাখবেন।

📄 প্রথম HTML ফাইল তৈরি

চলুন একটি ফাইল তৈরি করি ধাপে ধাপে:

১

নতুন ফাইল

VS Code ওপেন করুন → Ctrl + N চাপুন (Mac-এ Cmd + N)।

২

HTML টাইপ করুন

ফাইলে শুধু ! লিখে Tab চাপুন — সম্পূর্ণ HTML বয়লারপ্লেট অটো তৈরি হবে (Emmet ম্যাজিক)!

৩

সেভ করুন

Ctrl + S চাপুন। ফাইলের নাম দিন index.html এবং এক্সটেনশন অবশ্যই .html রাখুন।

৪

ব্রাউজারে খুলুন

ফাইলের উপর ডান-ক্লিক করে "Open with Live Server" এ ক্লিক করুন। অথবা ফাইলটি ডাবল-ক্লিক করলেই ডিফল্ট ব্রাউজারে খুলবে।

✍️ প্রথম কোড ও লাইভ ডেমো

এখন index.html ফাইলে নিচের কোডটি লিখুন:

<!DOCTYPE html> <html lang="bn"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>আমার প্রথম পেজ</title> </head> <body> <h1>হ্যালো, বাংলাদেশ!</h1> <p>আমি HTML শিখছি।</p> </body> </html>
✅ লাইভ আউটপুট

হ্যালো, বাংলাদেশ!

আমি HTML শিখছি।

📁 ফাইল ও ফোল্ডার গঠন

প্রজেক্ট যত বড় হবে, ফাইল গুছিয়ে রাখা তত জরুরি। একটি ভালো ফোল্ডার স্ট্রাকচার:

📁 html-lesson/ ├── index.html ← মূল ফাইল ├── about.html ← অন্য পেজ ├── 📁 images/ ← সব ছবি এখানে │ ├── profile.jpg │ └── banner.png ├── 📁 css/ ← CSS ফাইল │ └── style.css └── 📁 js/ ← JavaScript ফাইল └── script.js
💡 নিয়ম: • ফাইলের নাম সবসময় ছোট হাতের অক্ষরে রাখুন (index.html, about.html)
• স্পেসের বদলে আন্ডারস্কোর বা হাইফেন ব্যবহার করুন (my_photo.jpg)
• সব ছবি এক জায়গায়, সব CSS এক জায়গায় রাখুন

⚡ Emmet শর্টকাট (সময় বাঁচান!)

VS Code-এ Emmet বিল্ট-ইন থাকে। শুধু সংক্ষিপ্ত কোড লিখে Tab চাপলেই সম্পূর্ণ HTML তৈরি হয়:

লিখুনTab চাপলে যা হবে
!সম্পূর্ণ HTML5 বয়লারপ্লেট
h1<h1></h1>
p{হ্যালো}<p>হ্যালো</p>
ul>li*3৩টি li সহ ul
div.container<div class="ict-container"></div>
a[href="#"]<a href="#"></a>
💡 টিপস: Emmet শিখলে HTML লেখার গতি ৩-৪ গুণ বেড়ে যায়। শুরুতে অদ্ভুত লাগলেও অভ্যাস হলে দুর্দান্ত কাজে দেয়।

⚠️ নতুনদের সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ ফাইলের নাম index.txt রাখা — অবশ্যই index.html হতে হবে
  • ❌ <meta charset="UTF-8"> না দেওয়া — বাংলা ভাঙা দেখাবে
  • ❌ ট্যাগ না বন্ধ করা — <h1> লিখে </h1> ভুলে যাওয়া
  • ❌ ফাইলের নামে স্পেস রাখা — my page.html ভুল, my-page.html ঠিক
  • ❌ সব ফাইল একই ফোল্ডারে জমা রাখা — গুছিয়ে রাখুন
