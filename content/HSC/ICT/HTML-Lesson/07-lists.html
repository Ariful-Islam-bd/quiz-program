🔵 Unordered List (<ul>)

<ul> ট্যাগ বুলেট পয়েন্টের তালিকা তৈরি করে। প্রতিটি আইটেম <li> ট্যাগে থাকে।

<ul> <li>আম</li> <li>জাম</li> <li>কাঁঠাল</li> </ul>
✅ লাইভ আউটপুট
  • আম
  • জাম
  • কাঁঠাল

🔹 type অ্যাট্রিবিউট

বুলেটের চেহারা বদলাতে type ব্যবহার করুন:

type="disc" (ডিফল্ট)

<ul type="disc">
  • পূর্ণ বৃত্ত
  • বুলেট

type="circle"

<ul type="circle">
  • ফাঁপা বৃত্ত
  • সার্কেল

type="square"

<ul type="square">
  • বর্গাকার
  • স্কয়ার

type="none"

<ul type="none">
  • বুলেট নেই
  • শুধু টেক্সট

🔢 Ordered List (<ol>)

<ol> ট্যাগ নম্বরযুক্ত তালিকা তৈরি করে — যেখানে ক্রম গুরুত্বপূর্ণ।

<ol> <li>প্রথম ধাপ</li> <li>দ্বিতীয় ধাপ</li> <li>তৃতীয় ধাপ</li> </ol>
✅ লাইভ আউটপুট
  1. প্রথম ধাপ
  2. দ্বিতীয় ধাপ
  3. তৃতীয় ধাপ

🔹 start ও reversed

start="5"

<ol start="5">
  1. পাঁচ
  2. ছয়
  3. সাত

reversed

<ol reversed>
  1. তিন
  2. দুই
  3. এক
💡 মনে রাখবেন: start="5" দিলে ৫ থেকে শুরু হবে। reversed দিলে উল্টো ক্রমে দেখাবে। একসাথে দিলে — ৫, ৪, ৩... ইত্যাদি।

✅ লাইভ আউটপুট
  • ফল
    • আম
    • জাম
  • সবজি
    • আলু
    • পটল

📖 Description List (<dl>)

শব্দ ও তার সংজ্ঞা জোড়া আকারে দেখানোর জন্য <dl> ব্যবহার করা হয়। এতে থাকে:

  • <dt> — Definition Term (শব্দ)
  • <dd> — Definition Description (সংজ্ঞা)
<dl> <dt>HTML</dt> <dd>HyperText Markup Language — ওয়েবপেজের কাঠামো</dd> <dt>CSS</dt> <dd>Cascading Style Sheets — ডিজাইন</dd> </dl>
✅ লাইভ আউটপুট
HTML
HyperText Markup Language — ওয়েবপেজের কাঠামো
CSS
Cascading Style Sheets — ডিজাইন
💡 কখন ব্যবহার করবেন: গ্লোসারি, FAQ, শব্দকোষ, প্রোডাক্ট স্পেসিফিকেশন — যেখানে শব্দ-সংজ্ঞা জোড়া লাগে।

🎨 CSS দিয়ে লিস্ট স্টাইলিং

🔹 list-style-type

বুলেটের ধরন CSS দিয়ে বদলানো যায়:

<style> ul.disc { list-style-type: disc; } ul.circle { list-style-type: circle; } ul.square { list-style-type: square; } ol.decimal { list-style-type: decimal; } ol.alpha { list-style-type: lower-alpha; } ol.roman { list-style-type: upper-roman; } </style>

🔹 list-style-position

outside (ডিফল্ট)

  • লম্বা টেক্সট যাতে বোঝা যায় বুলেট বাইরে আছে

inside

  • লম্বা টেক্সট যাতে বোঝা যায় বুলেট ভিতরে

🔹 বুলেট সরানো ও কাস্টমাইজ

<style> /* বুলেট সরানো */ ul.no-bullet { list-style: none; padding-left: 0; } /* ইমোজি বুলেট */ ul.emoji { list-style: none; padding-left: 0; } ul.emoji li::before { content: "✅ "; margin-right: 6px; } </style>
✅ লাইভ আউটপুট
  • ✅ কাজ সম্পন্ন
  • ✅ আরেকটি কাজ
  • ✅ তৃতীয় কাজ

📋 লিস্ট ট্যাগের সারসংক্ষেপ

ট্যাগ/অ্যাট্রিবিউটকাজউদাহরণ
<ul>আনঅর্ডারড লিস্ট<ul>...</ul>
<ol>অর্ডারড লিস্ট<ol>...</ol>
<li>লিস্ট আইটেম<li>আইটেম</li>
<dl>ডেসক্রিপশন লিস্ট<dl>...</dl>
<dt>টার্ম (শব্দ)<dt>HTML</dt>
<dd>ডেসক্রিপশন<dd>মার্কআপ...</dd>
typeবুলেট/নম্বরের ধরনtype="square"
startশুরুর নম্বরstart="5"
reversedউল্টো ক্রম<ol reversed>

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ <li> ট্যাগ <ul>/<ol>-এর বাইরে ব্যবহার
  • ❌ <ul>-এর ভেতরে সরাসরি টেক্সট রাখা (আইটেম <li>-তে রাখতে হবে)
  • ❌ নেস্টেড লিস্ট <li>-এর ভেতরে না রেখে বাইরে রাখা
  • ❌ <dd> ছাড়া <dt> ব্যবহার
  • ❌ শুধু সাজানোর জন্য টেবিল ব্যবহার (লিস্টই যথেষ্ট)
  • ❌ মোবাইল রেসপন্সিভের জন্য padding ঠিক না করা

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • Unordered List: <ul> + <li> (বুলেট)
  • Ordered List: <ol> + <li> (নম্বর)
  • Description List: <dl> + <dt> + <dd>
  • type: disc, circle, square / 1, A, a, I, i
  • start/reversed: শুরু ও ক্রম নিয়ন্ত্রণ
  • Nested List: ভিতরে-বাইরে লিস্ট
  • CSS: list-style-type, list-style-position, ::before
  • বাস্তব উদাহরণ: To-Do, মেনু, স্টেপ
