🏷️ ট্যাগ, এলিমেন্ট, অ্যাট্রিবিউট

HTML-এর মৌলিক একক — ট্যাগ কী, এলিমেন্ট কী, অ্যাট্রিবিউট কীভাবে কাজ করে, নেস্টিং ও কমেন্ট — সবকিছু উদাহরণ সহ।

🔰 ট্যাগ কী? (What is a Tag?)

ট্যাগ হলো HTML-এর মূল একক — যা অ্যাঙ্গেল ব্র্যাকেট < > দিয়ে ঘেরা থাকে। ট্যাগ ব্রাউজারকে বলে দেয় কনটেন্টটি কী ধরনের।

🔹 Opening Tag

শুরু নির্দেশ করে

<h1> <p> <div>

🔸 Closing Tag

শেষ নির্দেশ করে (স্ল্যাশ সহ)

</h1> </p> </div>

⚡ Self-closing (Void)

শুরু ও শেষ একসাথে

<br> <hr> <img>
💡 মনে রাখবেন: Opening ট্যাগ ও Closing ট্যাগ একই নামের হয়, শুধু Closing-এ একটি / থাকে। যেমন <h1> → </h1>

🧩 এলিমেন্ট কী? (What is an Element?)

এলিমেন্ট হলো Opening Tag + Content + Closing Tag — তিনটি একসাথে। অর্থাৎ:

<h1>স্বাগতম</h1>
Opening Tag
Content
Closing Tag
<h1>স্বাগতম</h1> <!-- সম্পূর্ণ এলিমেন্ট --> <p>এটি একটি প্যারাগ্রাফ</p> <!-- আরেকটি এলিমেন্ট -->
✅ লাইভ আউটপুট

স্বাগতম

এটি একটি প্যারাগ্রাফ

📋 ট্যাগ vs এলিমেন্ট vs অ্যাট্রিবিউট

পরিভাষাসংজ্ঞাউদাহরণ
ট্যাগ অ্যাঙ্গেল ব্র্যাকেট দিয়ে ঘেরা নির্দেশ <p>
এলিমেন্ট Opening + Content + Closing <p>হ্যালো</p>
অ্যাট্রিবিউট ট্যাগে অতিরিক্ত তথ্য যোগ করে href="page.html"

🎛️ অ্যাট্রিবিউট কী? (What is an Attribute?)

অ্যাট্রিবিউট হলো Opening Tag-এর ভেতরে লেখা অতিরিক্ত তথ্য, যা এলিমেন্টকে কাস্টমাইজ করে। যেমন একটি লিংকের গন্তব্য, একটি ছবির সোর্স, একটি প্যারাগ্রাফের স্টাইল ইত্যাদি।

<a  href="about.html">আমার সম্পর্কে</a>
Opening
Attribute Name
Attribute Value
Content

📌 পরিচিত কিছু অ্যাট্রিবিউট

href লিংকের ঠিকানা — <a href="page.html">
src ছবির সোর্স — <img src="photo.jpg">
alt ছবির বিকল্প টেক্সট — <img alt="ফুলের ছবি">
id ইউনিক আইডেন্টিফায়ার — <div id="header">
class গ্রুপ নাম — <p class="ict-note">
style ইনলাইন CSS — <p style="color:red;">
title টুলটিপ — <abbr title="HyperText">

💡 অ্যাট্রিবিউটের নিয়ম

  • ✅ সবসময় Opening Tag-এ থাকে
  • ✅ সাধারণত name="value" ফরম্যাটে থাকে
  • ✅ Value সবসময় কোটেশন মার্কে (" ") রাখা ভালো
  • ✅ একটি এলিমেন্টে একাধিক অ্যাট্রিবিউট থাকতে পারে
  • ✅ কিছু অ্যাট্রিবিউটের মান লাগে না (যেমন required)
<!-- একাধিক অ্যাট্রিবিউটের উদাহরণ --> <img src="profile.jpg" alt="প্রোফাইল ছবি" width="200" height="200">

🔗 Void ট্যাগ (Self-closing Tags)

কিছু ট্যাগের Closing Tag থাকে না — এগুলোকে Void ট্যাগ বা Self-closing ট্যাগ বলে। কারণ এদের ভেতরে কোনো কনটেন্ট থাকে না।

Void ট্যাগকাজউদাহরণ
<br>লাইন ব্রেকলাইন ভাঙতে
<hr>হরাইজন্টাল লাইনসেকশন আলাদা করতে
<img>ছবিছবি দেখাতে
<input>ইনপুট ফিল্ডফর্মে ব্যবহার
<meta>মেটাডেটাhead-এ ব্যবহার
<link>বাহ্যিক ফাইলCSS যুক্ত করতে
💡 দুই পদ্ধতিই চলে: <br> এবং <br /> — দুটোই বৈধ। HTML5-এ শেষের স্ল্যাশ বাধ্যতামূলক নয়, তবে XHTML-এ দরকার হয়।

📦 নেস্টিং (Nesting) — ভিতরে-বাইরে

HTML এলিমেন্টগুলো একটির ভেতরে আরেকটি রাখা যায় — এটাকে নেস্টিং বলে। যেমন একটি <div>-এর ভেতরে একটি <p> থাকতে পারে।

<div> <h1>শিরোনাম</h1> <p>একটি প্যারাগ্রাফ</p> <ul> <li>আইটেম ১</li> <li>আইটেম ২</li> </ul> </div>
✅ লাইভ আউটপুট

শিরোনাম

একটি প্যারাগ্রাফ

  • আইটেম ১
  • আইটেম ২

⚠️ নেস্টিং-এর নিয়ম

সঠিক নেস্টিং না করলে ব্রাউজার ভুলভাবে রেন্ডার করতে পারে!
✅ সঠিক:
<p><strong>গুরুত্বপূর্ণ</strong></p>

❌ ভুল:
<p><strong>গুরুত্বপূর্ণ</p></strong> ← ট্যাগ আগে-পরে হয়ে গেছে

💬 কমেন্ট (Comments)

HTML কমেন্ট হলো এমন কোড যা ব্রাউজার দেখায় না, শুধু কোডে নোট হিসেবে থাকে। ডেভেলপাররা ব্যাখ্যা বা সাময়িক বন্ধ রাখতে ব্যবহার করেন।

<!-- এটি একটি কমেন্ট, ব্রাউজারে দেখা যাবে না --> <p>এটি দেখা যাবে</p> <!-- মাল্টিলাইন কমেন্টও সম্ভব এখানে যা লিখবেন, ব্রাউজার দেখবে না -->
✅ লাইভ আউটপুট

এটি দেখা যাবে

📌 কমেন্ট কেন ব্যবহার করবেন?

  • ✅ কোডের উদ্দেশ্য ব্যাখ্যা করতে
  • ✅ সাময়িকভাবে কোনো কোড বন্ধ রাখতে
  • ✅ ভবিষ্যতে নিজেকে মনে করিয়ে দিতে
  • ✅ টিমের অন্যদের বোঝাতে
💡 শর্টকাট: VS Code-এ কমেন্ট করতে Ctrl + / (Mac-এ Cmd + /) চাপুন।

📐 ইন্ডেন্টেশন (Indentation) — কোড সাজানো

কোড সুন্দরভাবে সাজিয়ে লেখা (indentation) অত্যন্ত গুরুত্বপূর্ণ — যদিও ব্রাউজার এটি দেখে না, কিন্তু ডেভেলপারের জন্য এটি অপরিহার্য।

❌ খারাপ ইন্ডেন্টেশন

<div><h1>শিরোনাম</h1><p>প্যারাগ্রাফ</p><ul><li>১</li><li>২</li></ul></div>

✅ ভালো ইন্ডেন্টেশন

<div> <h1>শিরোনাম</h1> <p>প্যারাগ্রাফ</p> <ul> <li>১</li> <li>২</li> </ul> </div>
💡 নিয়ম: প্রতিটি নেস্টিং লেভেলে ২ স্পেস (বা ৪ স্পেস) ইনডেন্ট দিন। VS Code-এ Shift + Alt + F চাপলে অটো ফরম্যাট হবে।

⚠️ নতুনদের সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ Closing Tag ভুলে যাওয়া — <p> খুলে </p> না দেওয়া
  • ❌ ভুল নেস্টিং — <b><i>টেক্সট</b></i> (ভুল ক্রম)
  • ❌ Void ট্যাগে Closing দিতে চেষ্টা — <br></br> (ভুল)
  • ❌ অ্যাট্রিবিউটে কোটেশন না দেওয়া — class=note (কোটেশন ছাড়া ঝুঁকিপূর্ণ)
  • ❌ ট্যাগের নাম ভুল বানান — <heder> নয়, <header>
  • ❌ ইন্ডেন্টেশন না দেওয়া — কোড পড়া কঠিন হয়

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • ট্যাগ = < > দিয়ে ঘেরা নির্দেশ
  • এলিমেন্ট = Opening + Content + Closing
  • অ্যাট্রিবিউট = ট্যাগে অতিরিক্ত তথ্য
  • Void ট্যাগ = Closing লাগে না (<br>, <img>)
  • নেস্টিং = ভিতরে-বাইরে সঠিক ক্রম
  • কমেন্ট = <!-- --> দিয়ে নোট
  • ইন্ডেন্টেশন = কোড সাজিয়ে লেখা
