⚡ Flexbox পরিচিতি

display:flex, flex-direction, justify-content, align-items, gap — সবচেয়ে বেশি ব্যবহৃত Flexbox প্রোপার্টিগুলো লাইভ ডেমো সহ।

🔰 Flexbox কী?

Flexbox (Flexible Box) হলো CSS-এর একটি লেআউট মডেল, যা দিয়ে সহজে এলিমেন্টগুলোকে সারি বা কলামে সাজানো যায়। আগে লেআউট করতে float, position ইত্যাদি কঠিন পদ্ধতি ব্যবহার হতো — Flexbox সেগুলো সহজ করে দিয়েছে।

💡 মূল ধারণা: Flexbox-এ দুটি জিনিস থাকে — Flex Container (বাইরের বাক্স) এবং Flex Items (ভেতরের এলিমেন্ট)। Container-এ display: flex; দিলেই Flexbox চালু হয়।
.container { display: flex; /* Flexbox চালু */ }

📏 justify-content — প্রধান অক্ষ বরাবর

মূল অক্ষ (main axis) বরাবর items কীভাবে সাজবে তা নির্ধারণ করে। flex-direction: row হলে এটি হরাইজন্টাল (বাম-ডান), column হলে ভার্টিকাল (উপর-নিচ)।

📏 gap — Items-এর মাঝে ফাঁকা

Items-এর মাঝে সমান ফাঁকা জায়গা রাখার সবচেয়ে সহজ উপায়:

gap ছাড়া

.container { display: flex; gap: 16px; /* Items-এর মাঝে ১৬px ফাঁকা */ }
💡 gap ব্যবহারের সুবিধা: আগে margin দিয়ে ফাঁকা করতে হতো, যেখানে প্রথম/শেষ item-এ বাড়তি margin থাকতো। gap শুধু items-এর মাঝে ফাঁকা দেয় — কোনো বাড়তি margin নেই।

🎯 কেন্দ্রীভূত কনটেন্ট (Centering)

একটি এলিমেন্টকে সম্পূর্ণ কেন্দ্রে রাখার সবচেয়ে সহজ উপায়:

.container { display: flex; justify-content: center; /* হরাইজন্টাল */ align-items: center; /* ভার্টিকাল */ height: 200px; }
🎯 আমি মাঝখানে

💼 বাস্তব উদাহরণ: নেভিগেশন বার

লোগো বামে, মেনু ডানে — Flexbox-এর সবচেয়ে বেশি ব্যবহৃত প্যাটার্ন:

.navbar { display: flex; justify-content: space-between; align-items: center; padding: 12px 20px; background: #1e293b; } .nav-links { display: flex; gap: 20px; }

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ display: flex; না দিয়ে justify-content ব্যবহার — কাজ করবে না
  • ❌ justify-content ও align-items গুলিয়ে ফেলা
  • ❌ margin দিয়ে ফাঁকা তৈরি — gap ভালো
  • ❌ flex-direction না বুঝে axis নিয়ে ভুল করা
  • ❌ মোবাইলে responsive না করা — media query দিয়ে flex-direction: column করুন

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • display: flex: Flexbox চালু করে
  • flex-direction: row / column / reverse
  • justify-content: মূল অক্ষ বরাবর সাজানো
  • align-items: লম্ব অক্ষ বরাবর সাজানো
  • gap: Items-এর মাঝে ফাঁকা
  • flex: 1: সমান জায়গা ভাগ করে নেয়
  • কেন্দ্রীভূত: justify-content + align-items = center
  • বাস্তব ব্যবহার: নেভিগেশন বার, কার্ড লেআউট, সেন্টারিং
