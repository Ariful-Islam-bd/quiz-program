📊 টেবিল (Tables)

টেবিল তৈরি, rowspan/colspan, CSS দিয়ে ডিজাইন, রেসপন্সিভ টেবিল ও অ্যাক্সেসিবিলিটি — সবকিছু উদাহরণ সহ।

🔰 টেবিলের মৌলিক গঠন

HTML টেবিল তৈরি হয় কয়েকটি মূল ট্যাগ দিয়ে:

<table> <!-- পুরো টেবিল --> <tr> <!-- Table Row (সারি) --> <th>নাম</th> <!-- Header Cell --> <th>রোল</th> </tr> <tr> <td>রহিম</td> <!-- Data Cell --> <td>০১</td> </tr> </table>
<table> <tr> <th>নাম</th> <th>রোল</th> </tr> <tr> <td>রহিম</td> <td>০১</td> </tr> <tr> <td>করিম</td> <td>০২</td> </tr> </table>
✅ লাইভ আউটপুট
নাম রোল
রহিম ০১
করিম ০২

📋 মূল ট্যাগসমূহ

ট্যাগকাজ
<table>পুরো টেবিল ধারণ করে
<tr>Table Row — একটি সারি
<th>Table Header — হেডার সেল (বোল্ড, সেন্টার)
<td>Table Data — সাধারণ ডেটা সেল
<caption>টেবিলের শিরোনাম/বর্ণনা

🏗️ thead, tbody, tfoot

বড় টেবিলে ডেটা গুছিয়ে রাখতে তিনটি সেকশন ট্যাগ ব্যবহার করা হয়:

<table> <caption>ছাত্রদের তথ্য</caption> <thead> <!-- হেডার সেকশন --> <tr><th>নাম</th><th>রোল</th></tr> </thead> <tbody> <!-- মূল ডেটা --> <tr><td>রহিম</td><td>০১</td></tr> </tbody> <tfoot> <!-- ফুটার সেকশন --> <tr><td>মোট: ১ জন</td></tr> </tfoot> </table>

💡 কেন sectioning জরুরি? <thead>, <tbody>, <tfoot> দিলে স্ক্রিন রিডার টেবিলের গঠন বুঝতে পারে। ব্রাউজারে হেডার আলাদা দেখানো বা প্রিন্টে প্রতিটি পেজে হেডার পুনরাবৃত্তি করা যায়।

🔀 colspan ও rowspan

একাধিক কলাম বা সারি একসাথে জোড়া লাগাতে ব্যবহার হয়:

🔹 colspan — কলাম মার্জ

একটি সেল কয়টি কলাম জুড়ে থাকবে তা নির্ধারণ করে।

<tr> <td colspan="2">২ কলাম জুড়ে</td> </tr>
সেল ১ colspan=2
সেল ৩ সেল ৪ সেল ৫

🔹 rowspan — সারি মার্জ

একটি সেল কয়টি সারি জুড়ে থাকবে তা নির্ধারণ করে।

<tr> <td rowspan="2">২ সারি জুড়ে</td> <td>সেল ২</td> </tr> <tr> <td>সেল ৩</td> </tr>
rowspan=2 সেল ২
সেল ৩
💡 ব্যবহার: colspan দিয়ে টেবিলের শিরোনাম পুরো প্রস্থ জুড়ে দেখানো হয়, rowspan দিয়ে সময়সূচি (একটি ইভেন্ট কয়েক ঘণ্টা চললে) দেখানো হয়।

🎯 scope অ্যাট্রিবিউট (অ্যাক্সেসিবিলিটি)

হেডার সেল (<th>) কোন দিকের জন্য কাজ করছে তা scope দিয়ে বোঝানো হয় — স্ক্রিন রিডারের জন্য জরুরি।

<th scope="col">কলাম হেডার</th> <th scope="row">সারি হেডার</th>

🎨 CSS দিয়ে টেবিল ডিজাইন

🔹 border-collapse

ডিফল্টভাবে টেবিলের সেলের বর্ডার আলাদা থাকে (ডাবল দেখায়)। border-collapse: collapse; দিলে একক বর্ডার হয়:

<style> table { border-collapse: collapse; /* একক বর্ডার */ width: 100%; } th, td { border: 1px solid #ddd; padding: 12px; text-align: left; } </style>

🔹 জেব্রা স্ট্রাইপিং

সারিগুলো এক-এক করে আলাদা রঙে দেখালে পড়তে সহজ হয়:

<style> tbody tr:nth-child(even) { background: #f8fafc; } </style>

🔹 হোভার ইফেক্ট

<style> tbody tr:hover { background: #e0e7ff; cursor: pointer; } </style>

📱 রেসপন্সিভ টেবিল

মোবাইলে বড় টেবিল স্ক্রিনের বাইরে চলে যায়। সমাধান — একটি wrapper-এ overflow-x: auto দিন:

<style> .table-wrapper { overflow-x: auto; -webkit-overflow-scrolling: touch; border-radius: 8px; border: 1px solid #ddd; } .table-wrapper table { min-width: 600px; /* মোবাইলেও টেবিলের ন্যূনতম প্রস্থ */ } </style> <div class="table-wrapper"> <table>...</table> </div>

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ <td> ট্যাগ <tr>-এর বাইরে রাখা
  • ❌ টেবিল লেআউটের জন্য ব্যবহার (বর্তমানে CSS Flexbox/Grid ভালো)
  • ❌ colspan/rowspan-এর মান ভুল দেওয়া — টেবিল ভেঙে যায়
  • ❌ <th> ব্যবহার না করে <td>-কেই হেডার বানানো
  • ❌ মোবাইল রেসপন্সিভ না করা — টেবিল স্ক্রিনের বাইরে যায়
  • ❌ scope না দেওয়া — অ্যাক্সেসিবিলিটি কমে

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • বেসিক ট্যাগ: <table>, <tr>, <td>, <th>
  • সেকশন: <thead>, <tbody>, <tfoot>, <caption>
  • colspan: একাধিক কলাম জোড়া
  • rowspan: একাধিক সারি জোড়া
  • scope: অ্যাক্সেসিবিলিটির জন্য
  • CSS: border-collapse, striping, hover
  • রেসপন্সিভ: wrapper + overflow-x
  • প্রাইসিং টেবিল: কলাম হাইলাইট
