🎯 সিম্যান্টিক ট্যাগ কী?

🔍 প্রতিটি ট্যাগের বিস্তারিত

🔹 <header>

পেজ বা সেকশনের শিরোনাম অংশ। এতে লোগো, সাইটের নাম, নেভিগেশন থাকতে পারে।

<header> <h1>আমার ব্লগ</h1> <p>লেখালেখির জায়গা</p> </header>

🔹 <nav>

নেভিগেশন লিংকের গ্রুপ।

<nav> <a href="index.html">হোম</a> <a href="about.html">সম্পর্কে</a> </nav>

🔹 <main>

পেজের মূল কনটেন্ট। একটি পেজে শুধু একটি <main> থাকা উচিত।

🔹 <section>

একটি থিমভিত্তিক গ্রুপ। সাধারণত একটি শিরোনাম (<h2>) থাকে।

<section> <h2>আমাদের সার্ভিস</h2> <p>আমরা যা যা করি...</p> </section>

🔹 <article>

স্বতন্ত্র কনটেন্ট — যেমন ব্লগ পোস্ট, নিউজ আর্টিকেল, ফোরাম পোস্ট। এটি আলাদা করে অন্য জায়গায় রাখলেও অর্থপূর্ণ থাকে।

<article> <h2>HTML শেখার ৫টি টিপস</h2> <p>লেখকের নাম</p> <p>ব্লগের মূল কনটেন্ট...</p> </article>

🔹 <aside>

মূল কনটেন্টের সাথে সম্পর্কিত কিন্তু আলাদা রাখা যায় এমন তথ্য — বিজ্ঞাপন, সাইডবার, সম্পর্কিত লিংক।

🔹 <footer>

পেজ বা সেকশনের নিচের অংশ। কপিরাইট, যোগাযোগ, লিংক ইত্যাদি থাকে।

<footer> <p>© ২০২৪ আমার সাইট</p> <a href="privacy.html">প্রাইভেসি</a> </footer>

🔹 <figure> + <figcaption>

ছবি ও তার ক্যাপশন একসাথে।

🔹 <time>

তারিখ বা সময় বোঝাতে। সার্চ ইঞ্জিন ও স্ক্রিন রিডার বুঝতে পারে।

📊 div vs সিম্যান্টিক ট্যাগ

div দিয়ে (খারাপ)সিম্যান্টিক দিয়ে (ভালো)
<div class="header"><header>
<div class="nav"><nav>
<div class="main"><main>
<div class="content"><article>
<div class="sidebar"><aside>
<div class="footer"><footer>
💡 মনে রাখবেন: সিম্যান্টিক ট্যাগের কাজ <div>-ও করা যায়, কিন্তু সিম্যান্টিক ট্যাগ ব্যবহার করলে ব্রাউজার, সার্চ ইঞ্জিন ও স্ক্রিন রিডার সবাই পেজের গঠন ভালো বুঝতে পারে।

🎨 সিম্যান্টিক ট্যাগে CSS

সিম্যান্টিক ট্যাগগুলোতে CSS দিয়ে ডিজাইন করা যায়:

<style> header { background: #6366f1; color: white; padding: 20px; text-align: center; } nav { background: #1e293b; padding: 10px; } nav a { color: white; margin: 0 15px; text-decoration: none; } main { display: flex; gap: 20px; padding: 20px; } article { flex: 2; background: #f8fafc; padding: 20px; } aside { flex: 1; background: #fef3c7; padding: 20px; } footer { background: #1e293b; color: white; text-align: center; padding: 15px; } </style>
💡 টিপস: <header>, <footer> ইত্যাদি সিম্যান্টিক ট্যাগকে সরাসরি CSS সিলেক্টর হিসেবে ব্যবহার করা যায় — আলাদা ক্লাসের দরকার নেই।

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ সবকিছুতেই <div> ব্যবহার — সিম্যান্টিক ট্যাগ এড়িয়ে যাওয়া
  • ❌ একাধিক <main> একটি পেজে রাখা
  • ❌ <article> এর ভিতরে <main> রাখা — main শুধু একবার, শীর্ষ লেভেলে
  • ❌ <header>/<footer> সবসময় পেজে একবার হবে — না, একাধিক সেকশনেও হতে পারে
  • ❌ <nav>-এর ভিতরে non-navigation লিংক রাখা
  • ❌ <section>-এ শিরোনাম (<h2>) না দেওয়া
💡 নিয়ম: <section>-এর ভিতরে সাধারণত একটি শিরোনাম (<h2>-<h6>) থাকা উচিত — এটি সেকশনের বিষয় বোঝায়। শিরোনাম ছাড়া <div> ব্যবহার করা ভালো।

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • div: Block কনটেইনার (পুরো প্রস্থ)
  • span: Inline কনটেইনার (টেক্সটের অংশ)
  • <header>: পেজ/সেকশনের হেডার
  • <nav>: নেভিগেশন মেনু
  • <main>: মূল কনটেন্ট (একবার)
  • <section>: থিমভিত্তিক সেকশন
  • <article>: স্বতন্ত্র কনটেন্ট
  • <aside>: সাইডবার
  • <footer>: ফুটার
  • <figure> + <figcaption>: ক্যাপশনসহ ছবি
  • <time>: তারিখ/সময়
