📖 HTML পরিচিতি

HTML কী, কেন শিখব, ওয়েবপেজ কীভাবে কাজ করে এবং HTML ফাইলের মূল গঠন — সবকিছু এই মডিউলে।

🔰 HTML কী? (What is HTML?)

HTML এর পূর্ণরূপ HyperText Markup Language। এটি একটি মার্কআপ ল্যাংগুয়েজ — প্রোগ্রামিং ল্যাংগুয়েজ নয়। HTML দিয়ে আমরা ওয়েবপেজের কাঠামো (structure) তৈরি করি — কী শিরোনাম হবে, কোথায় ছবি থাকবে, কোথায় লিংক থাকবে ইত্যাদি।

  • 🔹 HyperText: এক পেজ থেকে অন্য পেজে লিংকের মাধ্যমে যাওয়া
  • 🔹 Markup: ট্যাগ দিয়ে কনটেন্ট চিহ্নিত করা
  • 🔹 Language: নির্দিষ্ট নিয়ম-কানুনের ভাষা
💡 সহজ কথায়: HTML হলো ওয়েবপেজের "হাড়গোড়" বা কাঠামো। যেমন একটি বাড়ির ইট-পাথর হলো HTML, রং-রূপ হলো CSS, আর দরজা-জানালার মতো কাজ হলো JavaScript।

🎯 কেন HTML শিখব? (Why Learn HTML?)

  • ✅ ওয়েবের ভিত্তি: পৃথিবীর প্রতিটি ওয়েবপেজ HTML দিয়ে তৈরি
  • ✅ সহজ ও শেখার যোগ্য:প্রোগ্রামিং লজিক ছাড়াই কাঠামো তৈরি করা যায়
  • ✅ CSS ও JavaScript-এর ভিত্তি: এগুলো শিখতে HTML জানা বাধ্যতামূলক
  • ✅ ক্যারিয়ার: ওয়েব ডেভেলপমেন্টের প্রথম ধাপ
  • ✅ নিজের সাইট: ব্লগ, পোর্টফোলিও, ব্যবসার সাইট তৈরি করা যায়
  • ✅ SEO: সিম্যান্টিক HTML সার্চ ইঞ্জিনে র‍্যাংকিং উন্নত করে

🌐 ওয়েবপেজ কীভাবে কাজ করে?

আপনি যখন ব্রাউজারে কোনো ঠিকানা লেখেন, তখন পর্দার পিছনে ধাপে ধাপে কিছু কাজ হয়:

👤 আপনি URL লেখেন → 🌍 সার্ভারে অনুরোধ → 📄 HTML ফাইল আসে → 🖥️ ব্রাউজার রেন্ডার করে
  • ১. আপনি ব্রাউজারে example.com লেখেন
  • ২. ব্রাউজার সার্ভারে অনুরোধ পাঠায় (HTTP Request)
  • ৩. সার্ভার HTML ফাইল ফেরত পাঠায়
  • ৪. ব্রাউজার HTML পড়ে, বিশ্লেষণ করে (Parse) এবং পর্দায় দেখায় (Render)
💡 মনে রাখবেন: ব্রাউজার HTML-কে "পড়ে" বোঝে না — এটি ট্যাগগুলোকে নির্দেশ হিসেবে ব্যবহার করে পেজ সাজায়। যেমন <h1> দেখলে ব্রাউজার বোঝে এটি একটি বড় শিরোনাম।

🏗️ HTML ফাইলের মূল গঠন

প্রতিটি HTML ফাইলের একটি নির্দিষ্ট কাঠামো থাকে। নিচের কোডটি একটি সম্পূর্ণ HTML পেজের উদাহরণ:

<!DOCTYPE html> <!-- ডকুমেন্ট টাইপ: HTML5 বোঝায় --> <html lang="bn"> <!-- মূল ট্যাগ, ভাষা বাংলা --> <head> <meta charset="UTF-8"> <!-- বাংলা অক্ষরের জন্য --> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>আমার প্রথম পেজ</title> </head> <body> <h1>স্বাগতম!</h1> <p>এটি আমার প্রথম HTML পেজ।</p> </body> </html>

🔍 প্রতিটি অংশের ব্যাখ্যা

ট্যাগকাজ
<!DOCTYPE html>ডকুমেন্টটি HTML5 — ব্রাউজারকে জানায়
<html>পুরো ডকুমেন্টের মূল ধারক
<head>পেজের মেটাডেটা (শিরোনাম, এনকোডিং) — ব্যবহারকারী দেখে না
<meta>অতিরিক্ত তথ্য (অক্ষর এনকোডিং, ভিউপোর্ট)
<title>ব্রাউজার ট্যাবে যে শিরোনাম দেখায়
<body>পেজের দৃশ্যমান অংশ — এখানে সব কনটেন্ট থাকে
⚠️ গুরুত্বপূর্ণ: <meta charset="UTF-8"> না দিলে বাংলা লেখা ভাঙা দেখাবে (যেমন: à¦¬à¦¾à¦‚à¦²à¦¾)। তাই সবসময় এটি যুক্ত করবেন।

✅ লাইভ আউটপুট

এটি আমার প্রথম HTML পেজ।

ব্রাউজারের ট্যাবে "আমার প্রথম পেজ" লেখাটি দেখা যাবে — সেটি <title> ট্যাগ থেকে আসছে।

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • HTML = HyperText Markup Language — ওয়েবপেজের কাঠামো
  • HTML প্রোগ্রামিং ল্যাংগুয়েজ নয়, মার্কআপ ল্যাংগুয়েজ
  • HTML + CSS + JS = সম্পূর্ণ ওয়েবপেজ
  • ব্রাউজার সার্ভার থেকে HTML নিয়ে রেন্ডার করে
  • HTML ফাইলের মূল গঠন: <!DOCTYPE>, <html>, <head>, <body>
  • <meta charset="UTF-8"> বাংলার জন্য অপরিহার্য
