📅 ক্যালেন্ডার তৈরি

এখন পর্যন্ত শেখা টেবিল, CSS ও স্টাইলিং একসাথে প্রয়োগ করে একটি সম্পূর্ণ ক্যালেন্ডার তৈরি করব।

🎯 প্রজেক্টের লক্ষ্য

এই প্রজেক্টে আমরা একটি মাসিক ক্যালেন্ডার তৈরি করব যা:

  • ✅ টেবিল দিয়ে তৈরি (৭ কলাম — সপ্তাহের ৭ দিন)
  • ✅ ৫–৬ সারি (মাসের দিনগুলো)
  • ✅ শুক্র ও শনিবার সাপ্তাহিক ছুটি হিসেবে হাইলাইট
  • ✅ "আজকের দিন" বিশেষভাবে চিহ্নিত
  • ✅ মোবাইল রেসপন্সিভ
💡 কী শিখব? এই প্রজেক্টে প্রয়োগ হবে — টেবিল গঠন, CSS স্টাইলিং, pseudo-class, রেসপন্সিভ ডিজাইন, কালার স্কিম।

🔹 CSS-এর গুরুত্বপূর্ণ অংশ

border-collapse: collapse; — টেবিলের সেলের বর্ডার একসাথে লেগে যায় (ডাবল বর্ডার হয় না)।

caption-এ gradient:

caption { background: linear-gradient(135deg, #6366f1, #8b5cf6); color: white; padding: 14px; font-size: 1.4em; }

.weekend এবং .weekendth:

.weekend { background: #ffe4e6; color: #ef4444; font-weight: bold; } .weekendth { background: #db2777; /* শুক্র-শনির হেডার */ }

.today:

.today { background: #fef3c7; /* হলুদ ব্যাকগ্রাউন্ড */ border: 2px solid #f59e0b; /* কমলা বর্ডার */ font-weight: bold; }

রেসপন্সিভ:

@media (max-width: 600px) { td { font-size: 0.85em; height: 34px; padding: 6px 2px; } th { font-size: 0.7em; padding: 6px 2px; } caption { font-size: 1.1em; } }

🚀 আপনার চ্যালেঞ্জ

এই ক্যালেন্ডার তৈরি করার পর নিচের কাজগুলো নিজে নিজে করুন:

🎯 চ্যালেঞ্জ ১: অন্য একটি মাসের (যেমন এপ্রিল ২০২৬) ক্যালেন্ডার বানান। মনে রাখবেন — এপ্রিল ১ তারিখ কোন বার?
🎯 চ্যালেঞ্জ ২: প্রতিটি দিনের নিচে ছোট করে তারিখ লেখার বদলে তার সাথে ছুটির নাম বা বিশেষ দিন যোগ করুন (যেমন: ২৬ মার্চ — স্বাধীনতা দিবস)।
🎯 চ্যালেঞ্জ ৩: ক্যালেন্ডারের উপরে একটি "আগের মাস / পরের মাস" বাটন যোগ করুন (CSS দিয়ে সাজান)।
🎯 চ্যালেঞ্জ ৪: দিনগুলোতে হোভার করলে হালকা ব্যাকগ্রাউন্ড আসে — এই ইফেক্ট যোগ করুন :hover দিয়ে।
🎯 চ্যালেঞ্জ ৫ (অ্যাডভান্সড): JavaScript দিয়ে আজকের তারিখ স্বয়ংক্রিয়ভাবে হাইলাইট করুন — new Date() ব্যবহার করে।

✨ এই প্রজেক্টে নতুন কী শিখলেন

✅ কোডিং দক্ষতা:
  • টেবিল দিয়ে ক্যালেন্ডারের মতো জটিল লেআউট তৈরি
  • একাধিক CSS ক্লাস দিয়ে আলাদা অংশ স্টাইল করা
  • গ্রেডিয়েন্ট ব্যাকগ্রাউন্ড ব্যবহার
  • মোবাইল রেসপন্সিভ টেবিল ডিজাইন
  • ক্লাসের নামকরণের সঠিক পদ্ধতি (weekend, today, empty)
💡 বাস্তব ব্যবহার: এই কৌশল ব্যবহার করে আপনি বানাতে পারবেন — সময়সূচি, উপস্থিতি শীট, বুকিং ক্যালেন্ডার, ট্রেন/বাসের সময়সূচি, পরীক্ষার রুটিন ইত্যাদি।
