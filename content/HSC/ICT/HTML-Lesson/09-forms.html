📝 ফর্ম (Forms)

ইনপুট টাইপ, লেবেল, সিলেক্ট, ভ্যালিডেশন ও প্রফেশনাল ফর্ম ডিজাইন — সবকিছু লাইভ ডেমো সহ।

🔰 ফর্মের মৌলিক গঠন

HTML ফর্ম ব্যবহারকারীর কাছ থেকে ডেটা সংগ্রহ করে। মূল ট্যাগ <form>, এর ভেতরে <input>, <select>, <textarea> ইত্যাদি থাকে।

<form action="/submit" method="POST"> <label for="name">নাম:</label> <input type="text" id="name" name="name"> <button type="submit">জমা দিন</button> </form>

⚙️ form ট্যাগের গুরুত্বপূর্ণ অ্যাট্রিবিউট

অ্যাট্রিবিউটকাজউদাহরণ
actionডেটা কোথায় পাঠাবেaction="/submit"
methodGET বা POSTmethod="POST"
targetরেসপন্স কোথায় দেখাবেtarget="_blank"
autocompleteঅটোকমপ্লিটautocomplete="off"
novalidateভ্যালিডেশন বন্ধnovalidate

⌨️ ইনপুট টাইপসমূহ

<input> ট্যাগের type অ্যাট্রিবিউট দিয়ে বিভিন্ন ধরনের ফিল্ড তৈরি করা যায়:

text

সাধারণ টেক্সট

email

ইমেইল (ভ্যালিডেশন সহ)

password

পাসওয়ার্ড (লুকানো)

number

সংখ্যা (তীর দিয়ে বাড়ানো)

tel

ফোন নম্বর

date

তারিখ (ক্যালেন্ডার)

time

সময়

checkbox

একাধিক নির্বাচন

radio

একটি নির্বাচন

file

ফাইল আপলোড

color

কালার পিকার

range

স্লাইডার

url

ওয়েব ঠিকানা

search

সার্চ বক্স

hidden

লুকানো ডেটা

submit

সাবমিট বাটন

🔹 লাইভ ডেমো

✅ লাইভ ইনপুট ফিল্ড

🏷️ label ও for

প্রতিটি ইনপুটের সাথে <label> যুক্ত করা উচিত। for অ্যাট্রিবিউট ও ইনপুটের id মিলিয়ে দিলে লেবেলে ক্লিক করলেও ইনপুট ফোকাস হয়।

<label for="username">ইউজারনেম:</label> <input type="text" id="username">
✅ লাইভ ডেমো
💡 অ্যাক্সেসিবিলিটি: <label> স্ক্রিন রিডার ব্যবহারকারীদের জানায় ইনপুটটি কীসের জন্য। লেবেল ছাড়া ফর্ম অ্যাক্সেসিবল নয়।

✅ checkbox ও radio

🔹 checkbox — একাধিক নির্বাচন

<label> <input type="checkbox" name="hobby" value="reading"> পড়া </label>
✅ লাইভ ডেমো

আপনার শখ:

🔹 radio — একটি নির্বাচন

একই name দেওয়া radio-গুলোর মধ্যে শুধু একটি নির্বাচন করা যায়:

<label> <input type="radio" name="gender" value="male"> পুরুষ </label>
✅ লাইভ ডেমো

লিঙ্গ:

📋 select ও option

ড্রপডাউন তালিকা তৈরি করতে <select> ও প্রতিটি অপশনের জন্য <option> ব্যবহার করা হয়:

<select name="country"> <option value="bd">বাংলাদেশ</option> <option value="in" selected>পাকিস্তান</option> <option value="pk" disabled>ভারত</option> </select>
✅ লাইভ ডেমো
অ্যাট্রিবিউটকাজ
selectedডিফল্ট নির্বাচিত অপশন
disabledঅপশন নিষ্ক্রিয়
multipleএকাধিক নির্বাচন (select-এ)
sizeকতটি অপশন একসাথে দেখাবে

📄 textarea

বহু-লাইন টেক্সট লেখার জন্য <textarea> ব্যবহার করা হয়:

<textarea rows="4" cols="50" placeholder="আপনার মন্তব্য..."> </textarea>
✅ লাইভ ডেমো
💡 মনে রাখবেন: <textarea>-এর Closing ট্যাগ লাগে (Void ট্যাগ নয়)। একাধিক লাইন লেখা যায়।

🔘 বাটনের প্রকারভেদ

টাইপকাজ
type="submit"ফর্ম জমা দেয়
type="reset"ফর্ম রিসেট করে
type="button"সাধারণ বাটন (JS দিয়ে কাজ)
✅ লাইভ ডেমো

🗂️ fieldset ও legend

সংশ্লিষ্ট ফিল্ডগুলোকে একটি গ্রুপে বাঁধতে <fieldset> ব্যবহার করা হয়, আর গ্রুপের শিরোনাম হয় <legend>:

<fieldset> <legend>ব্যক্তিগত তথ্য</legend> <label>নাম: <input type="text"></label> <label>ইমেইল: <input type="email"></label> </fieldset>
✅ লাইভ ডেমো
👤 ব্যক্তিগত তথ্য

✅ HTML5 ভ্যালিডেশন

জাভাস্ক্রিপ্ট ছাড়াই ব্রাউজার নিজেই ফর্ম যাচাই করতে পারে:

অ্যাট্রিবিউটকাজউদাহরণ
requiredফিল্ড আবশ্যকrequired
minlengthন্যূনতম অক্ষরminlength="3"
maxlengthসর্বোচ্চ অক্ষরmaxlength="20"
min / maxসংখ্যার সীমাmin="1" max="100"
patternরেগুলার এক্সপ্রেশনpattern="[0-9]{11}"
placeholderসাহায্যকারী লেখাplaceholder="নাম লিখুন"
✅ লাইভ ডেমো (ভুল ইনপুট দিলে লাল বর্ডার)
💡 কীভাবে কাজ করে? ইনপুট ভুল হলে ব্রাউজার নিজেই সাবমিট আটকে দেয় এবং একটি বার্তা দেখায়। :invalid সিউডো-ক্লাস দিয়ে CSS দিয়েও স্টাইল করা যায়।

🎯 সম্পূর্ণ রেজিস্ট্রেশন ফর্ম

এখন পর্যন্ত শেখা সবকিছু একসাথে ব্যবহার করে একটি রেজিস্ট্রেশন ফর্ম:

✅ লাইভ ডেমো
📝 নতুন অ্যাকাউন্ট

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ <label> না দেওয়া — অ্যাক্সেসিবিলিটি নষ্ট
  • ❌ for ও id-এর মান না মেলানো
  • ❌ একই name না দেওয়া radio-গুলোতে — একাধিক সিলেক্ট হয়ে যায়
  • ❌ type না দেওয়া — ডিফল্ট text হয়, কিন্তু ভুল ধরনের ডেটা আসে
  • ❌ required না দেওয়া — খালি ফর্ম সাবমিট হয়ে যায়
  • ❌ placeholder-কে label হিসেবে ব্যবহার (ভুল)
  • ❌ পাসওয়ার্ডে type="text" ব্যবহার — পাসওয়ার্ড দেখা যায়

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • form ট্যাগ: action, method
  • ইনপুট টাইপ: text, email, password, number, date, color, range, file, checkbox, radio
  • label: for + id জোড়া
  • select + option: ড্রপডাউন
  • textarea: বহু-লাইন টেক্সট
  • button: submit, reset, button
  • fieldset + legend: ফিল্ড গ্রুপ
  • ভ্যালিডেশন: required, min, max, pattern, minlength
