🔗 লিংক ও নেভিগেশন

ওয়েবের মূল শক্তি — লিংক। ইন্টারনাল, এক্সটার্নাল, ইমেইল, ফোন, অ্যাংকর লিংক — সব ধরনের লিংক শিখুন উদাহরণ সহ।

🔰 লিংক কী? (What is a Link?)

লিংক হলো এক পেজ থেকে অন্য পেজে বা একই পেজের একটি অংশে যাওয়ার সেতু। HTML-এ লিংক তৈরি করা হয় <a> (anchor) ট্যাগ দিয়ে।

<a  href="about.html">আমার সম্পর্কে</a>
Anchor ট্যাগ
href (গন্তব্য)
Value
ক্লিকযোগ্য টেক্সট

✅ লাইভ আউটপুট

📄 ইন্টারনাল ও এক্সটার্নাল লিংক

🔹 ইন্টারনাল লিংক

একই ওয়েবসাইটের অন্য পেজে যেতে শুধু ফাইলের নাম/পাথ দিলেই হয়:

<!-- একই ফোল্ডারে --> <a href="about.html">আমার সম্পর্কে</a> <!-- সাব-ফোল্ডারে --> <a href="pages/contact.html">যোগাযোগ</a> <!-- প্যারেন্ট ফোল্ডারে --> <a href="../index.html">হোম</a>

🔹 এক্সটার্নাল লিংক

অন্য ওয়েবসাইটে যেতে সম্পূর্ণ URL দিতে হয় (https:// সহ):

<a href="https://www.google.com">Google</a> <!-- নতুন ট্যাবে খুলতে --> <a href="https://www.google.com" target="_blank" rel="noopener noreferrer"> Google (নতুন ট্যাবে) </a>

⚠️ নিরাপত্তা: target="_blank" ব্যবহার করলে সাথে rel="noopener noreferrer" দিতে ভুলবেন না — এটি নিরাপত্তা ঝুঁকি (Tabnabbing) থেকে বাঁচায়।

📧 ইমেইল ও ফোন লিংক

📍 অ্যাংকর লিংক (একই পেজের অংশে যাওয়া)

লম্বা পেজে দ্রুত নির্দিষ্ট সেকশনে যেতে অ্যাংকর লিংক ব্যবহার করা যায়। দুটি ধাপ:

  1. গন্তব্য এলিমেন্টে id অ্যাট্রিবিউট দিন: <h2 id="section1">
  2. লিংকে #id ব্যবহার করুন: href="#section1"
<!-- গন্তব্য --> <h2 id="chapter3">অধ্যায় ৩: HTML লিংক</h2> <!-- লিংক --> <a href="#chapter3">অধ্যায় ৩-এ যান</a> <!-- পেজের একেবারে উপরে যেতে --> <a href="#">উপরে ফিরুন</a>
💡 টিপস: href="#" শুধু পেজের একেবারে উপরে নিয়ে যায়। href="#top" দিয়ে একটি id="top" এলিমেন্টেও যাওয়া যায়।

🎨 লিংকের স্টাইলিং (CSS)

ডিফল্টভাবে লিংক নীল ও আন্ডারলাইন থাকে। CSS দিয়ে সুন্দর করা যায়:

<style> /* সাধারণ লিংক */ a { color: #6366f1; text-decoration: none; font-weight: 600; } /* হোভার */ a:hover { color: #8b5cf6; text-decoration: underline; } /* ভিজিট করা লিংক */ a:visited { color: #64748b; } /* অ্যাক্টিভ (ক্লিকের সময়) */ a:active { color: #ef4444; } /* বাটন স্টাইল লিংক */ a.btn { background: #6366f1; color: white; padding: 10px 20px; border-radius: 8px; } </style>

🔘 বাটন স্টাইল লিংক

⚠️ সাধারণ ভুল

সতর্ক থাকুন:
  • ❌ href অ্যাট্রিবিউট ভুলে যাওয়া — লিংক কাজ করবে না
  • ❌ target="_blank" এর সাথে rel="noopener" না দেওয়া
  • ❌ এক্সটার্নাল URL-এ https:// না দেওয়া — ব্রাউজার ভুল পাথে যাবে
  • ❌ "এখানে ক্লিক করুন" লেখা — বর্ণনামূলক লেখা ভালো ("লেসন ডাউনলোড করুন")
  • ❌ একই পেজে একাধিক এলিমেন্টে একই id দিয়ে অ্যাংকর লিংক
  • ❌ ফাইলের নামে স্পেস — about page.html ভুল, about-page.html ঠিক
💡 অ্যাক্সেসিবিলিটি টিপস: লিংকের লেখা বর্ণনামূলক রাখুন। স্ক্রিন রিডার ব্যবহারকারীরা শুনে বুঝতে পারেন কোথায় যাবে। "ক্লিক করুন" নয় — "HTML লেসন ডাউনলোড করুন"।

📝 সারসংক্ষেপ

✅ এই মডিউলে যা শিখলেন:
  • Anchor ট্যাগ: <a href="...">লেখা</a>
  • ইন্টারনাল লিংক: href="page.html"
  • এক্সটার্নাল লিংক: href="https://..."
  • নতুন ট্যাব: target="_blank" + rel="noopener"
  • ইমেইল: href="mailto:...", ফোন: href="tel:..."
  • অ্যাংকর লিংক: href="#id" + id="..."
  • ডাউনলোড: download অ্যাট্রিবিউট
  • ছবিকে লিংক: <a><img></a>
  • CSS স্টাইলিং: :hover, :visited, :active
