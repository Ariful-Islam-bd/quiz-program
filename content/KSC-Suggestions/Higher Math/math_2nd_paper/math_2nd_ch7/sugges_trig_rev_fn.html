উচ্চতর গণিত ২য় পত্র

সৃজনশীল প্রশ্নব্যাংক ও ব্যাখ্যামূলক সমাধান

বিপরীত ত্রিকোণমিতিক ফাংশন ও ত্রিকোণমিতিক সমীকরণ (৭.১, ৭.২)

প্রশ্ন - ১

উদ্দীপক: $f(x) = \sin^{-1}x$ এবং $g(x) = \cos x$

ক. $\tan^{-1}\frac{1}{2} + \tan^{-1}\frac{1}{3}$ এর মান নির্ণয় কর।
খ. $f\left\{\sqrt{2}\ g\left(\frac{\pi}{2} - \theta\right)\right\} + f\left\{\sqrt{g(2\theta)}\right\}$ এর মান নির্ণয় কর।
গ. সমাধান কর: $\sqrt{3}\ g(x) - g\left(\frac{\pi}{2} + x\right) = 1$ যখন $-2\pi < x < 2\pi$
১ নং প্রশ্নের সমাধান:
ক. সমাধান:
প্রদত্ত রাশি, $\tan^{-1}\frac{1}{2} + \tan^{-1}\frac{1}{3}$
$= \tan^{-1}\left( \frac{\frac{1}{2} + \frac{1}{3}}{1 - \frac{1}{2} \cdot \frac{1}{3}} \right)$
[সূত্র: $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\frac{x+y}{1-xy}$ প্রয়োগ করে]
$= \tan^{-1}\left( \frac{\frac{3 + 2}{6}}{1 - \frac{1}{6}} \right)$
[লব ও হরে লসাগু করে]
$= \tan^{-1}\left( \frac{\frac{5}{6}}{\frac{6 - 1}{6}} \right)$
[হরে বিয়োগ করে]
$= \tan^{-1}\left( \frac{\frac{5}{6}}{\frac{5}{6}} \right)$
$= \tan^{-1}(1)$
[লব ও হর কাটাকাটি করে]
$= \tan^{-1}\left(\tan\frac{\pi}{4}\right)$
[যেহেতু $\tan\frac{\pi}{4} = 1$]
$= \frac{\pi}{4}$
[যেহেতু $\tan^{-1}(\tan \theta) = \theta$]
$\therefore$ নির্ণেয় মান: $\frac{\pi}{4}$
খ. সমাধান:
উদ্দীপক হতে প্রাপ্ত: $f(x) = \sin^{-1}x$ এবং $g(x) = \cos x$
প্রথম অংশের বিশ্লেষণ:
$g\left(\frac{\pi}{2} - \theta\right) = \cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta$
[যেহেতু $\cos(\frac{\pi}{2} - \theta) = \sin\theta$]
অতএব, $f\left\{\sqrt{2}\ g\left(\frac{\pi}{2} - \theta\right)\right\} = f\left(\sqrt{2}\sin\theta\right) = \sin^{-1}\left(\sqrt{2}\sin\theta\right)$
দ্বিতীয় অংশের বিশ্লেষণ:
$g(2\theta) = \cos 2\theta$
অতএব, $f\left\{\sqrt{g(2\theta)}\right\} = f\left(\sqrt{\cos 2\theta}\right) = \sin^{-1}\left(\sqrt{\cos 2\theta}\right)$
সুতরাং, প্রদত্ত রাশি $= \sin^{-1}\left(\sqrt{2}\sin\theta\right) + \sin^{-1}\left(\sqrt{\cos 2\theta}\right)$
$= \sin^{-1}\left[ \left(\sqrt{2}\sin\theta\right)\sqrt{1 - \left(\sqrt{\cos 2\theta}\right)^2} + \left(\sqrt{\cos 2\theta}\right)\sqrt{1 - \left(\sqrt{2}\sin\theta\right)^2} \right]$
[সূত্র: $\sin^{-1}x + \sin^{-1}y = \sin^{-1}\left(x\sqrt{1-y^2} + y\sqrt{1-x^2}\right)$ প্রয়োগ করে]
$= \sin^{-1}\left[ \sqrt{2}\sin\theta \sqrt{1 - \cos 2\theta} + \sqrt{\cos 2\theta} \sqrt{1 - 2\sin^2\theta} \right]$
[বর্গমূল ও স্কয়ার উঠে গিয়ে]
$= \sin^{-1}\left[ \sqrt{2}\sin\theta \cdot \sqrt{2\sin^2\theta} + \sqrt{\cos 2\theta} \cdot \sqrt{\cos 2\theta} \right]$
[যেহেতু $1 - \cos 2\theta = 2\sin^2\theta$ এবং $1 - 2\sin^2\theta = \cos 2\theta$]
$= \sin^{-1}\left[ \sqrt{2}\sin\theta \cdot \left(\sqrt{2}\sin\theta\right) + \cos 2\theta \right]$
[বর্গমূল সরল করে]
$= \sin^{-1}\left[ 2\sin^2\theta + \cos 2\theta \right]$
$= \sin^{-1}\left[ 2\sin^2\theta + (1 - 2\sin^2\theta) \right]$
[যেহেতু $\cos 2\theta = 1 - 2\sin^2\theta$]
$= \sin^{-1}\left( 1 \right)$
[$2\sin^2\theta$ কেটে গিয়ে]
$= \sin^{-1}\left( \sin \frac{\pi}{2} \right) = \frac{\pi}{2}$
[যেহেতু $\sin\frac{\pi}{2} = 1$]
$\therefore$ নির্ণেয় মান: $\frac{\pi}{2}$
গ. সমাধান:
উদ্দীপক হতে $g(x) = \cos x$
প্রদত্ত সমীকরণ: $\sqrt{3}\ g(x) - g\left(\frac{\pi}{2} + x\right) = 1$
$\Rightarrow \sqrt{3}\cos x - \cos\left(\frac{\pi}{2} + x\right) = 1$
[$g(x)$ এর মান বসিয়ে]
$\Rightarrow \sqrt{3}\cos x - (-\sin x) = 1$
[যেহেতু $\cos(\frac{\pi}{2} + x) = -\sin x$]
$\Rightarrow \sqrt{3}\cos x + \sin x = 1$
সহগদ্বয়ের বর্গের সমষ্টির বর্গমূল $= \sqrt{(\sqrt{3})^2 + 1^2} = \sqrt{3+1} = \sqrt{4} = 2$
সমীকরণের উভয়পক্ষকে $2$ দ্বারা ভাগ করে পাই:
$\Rightarrow \frac{\sqrt{3}}{2}\cos x + \frac{1}{2}\sin x = \frac{1}{2}$
$\Rightarrow \cos x \cdot \cos\frac{\pi}{6} + \sin x \cdot \sin\frac{\pi}{6} = \frac{1}{2}$
[যেহেতু $\cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$ এবং $\sin\frac{\pi}{6} = \frac{1}{2}$]
$\Rightarrow \cos\left(x - \frac{\pi}{6}\right) = \cos\frac{\pi}{3}$
[সূত্র: $\cos A \cos B + \sin A \sin B = \cos(A - B)$]
আমরা জানি, $\cos \theta = \cos \alpha$ হলে $\theta = 2n\pi \pm \alpha$ ; যেখানে $n \in \mathbb{Z}$
$\Rightarrow x - \frac{\pi}{6} = 2n\pi \pm \frac{\pi}{3}$
$\Rightarrow x = 2n\pi \pm \frac{\pi}{3} + \frac{\pi}{6}$
[$\frac{\pi}{6}$ কে পক্ষান্তর করে]
ধনাত্মক (+) চিহ্ন নিয়ে: $x = 2n\pi + \frac{\pi}{3} + \frac{\pi}{6} = 2n\pi + \frac{\pi}{2}$
ঋণাত্মক (-) চিহ্ন নিয়ে: $x = 2n\pi - \frac{\pi}{3} + \frac{\pi}{6} = 2n\pi - \frac{\pi}{6}$
এখন, প্রদত্ত সীমার মধ্যে ($-2\pi < x < 2\pi$) $n$ এর মান বসাই:
• $n = 0$ হলে:
   $x = 0 + \frac{\pi}{2} = \frac{\pi}{2}$ (গ্রহণযোগ্য)
   $x = 0 - \frac{\pi}{6} = -\frac{\pi}{6}$ (গ্রহণযোগ্য)
• $n = 1$ হলে:
   $x = 2\pi + \frac{\pi}{2} = \frac{5\pi}{2}$ (সীমার বাইরে)
   $x = 2\pi - \frac{\pi}{6} = \frac{11\pi}{6}$ (গ্রহণযোগ্য)
• $n = -1$ হলে:
   $x = -2\pi + \frac{\pi}{2} = -\frac{3\pi}{2}$ (গ্রহণযোগ্য)
   $x = -2\pi - \frac{\pi}{6} = -\frac{13\pi}{6}$ (সীমার বাইরে)
$\therefore$ নির্ণেয় সমাধান: $x = -\frac{3\pi}{2}, -\frac{\pi}{6}, \frac{\pi}{2}, \frac{11\pi}{6}$
প্রশ্ন - ২

দৃশ্যকল্প - ১:

দৃশ্যকল্প - ২: $1 + \sin^2 x - 2\cos^2 x + 3\cos x = 3 - \cos^2 x$

ক. প্রমাণ কর যে, $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$
খ. প্রমাণ কর যে, $\sin^2\left(\cos^{-1}\frac{1}{x}\right) - \cos^2\left(\sin^{-1}\frac{1}{\sqrt{x}}\right) = \frac{2}{9}\ ;$ যেখানে $AB = 2, y = \sqrt{5}$
গ. দৃশ্যকল্প - ২ এ বর্ণিত সমীকরণটির সাধারণ সমাধান নির্ণয় কর।
২ নং প্রশ্নের সমাধান:
ক. সমাধান:
ধরি, $\sin^{-1}x = \theta$ ---------- (১)
$\Rightarrow x = \sin \theta$
[বিপরীত ফাংশনের সংজ্ঞানুসারে]
আমরা জানি, $\cos\left(\frac{\pi}{2} - \theta\right) = \sin \theta$
$\Rightarrow x = \cos\left(\frac{\pi}{2} - \theta\right)$
[$\sin \theta = x$ বসিয়ে]
$\Rightarrow \cos^{-1}x = \frac{\pi}{2} - \theta$
[উভয়পাশে বিপরীত কসাইন নিয়ে]
$\Rightarrow \theta + \cos^{-1}x = \frac{\pi}{2}$
[$-\theta$ কে পক্ষান্তর করে]
$\Rightarrow \sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$
[(১) নং হতে $\theta = \sin^{-1}x$ বসিয়ে]
$\therefore \sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$ (প্রমাণিত)
খ. সমাধান:
দৃশ্যকল্প - ১ চিত্র বিশ্লেষণ: সমকোণী ত্রিভুজ $\triangle ABC$-এ $\angle B = 90^\circ$। লম্ব $AB = 2$, ভূমি $BC = y = \sqrt{5}$ এবং অতিভুজ $AC = x$।
পিথাগোরাসের উপপাদ্য হতে: $AC^2 = AB^2 + BC^2$
$\Rightarrow x^2 = 2^2 + (\sqrt{5})^2 = 4 + 5 = 9$
$\Rightarrow x = \sqrt{9} = 3$
[দৈর্ঘ্য সর্বদা ধনাত্মক $x > 0$]
বামপক্ষ $= \sin^2\left(\cos^{-1}\frac{1}{x}\right) - \cos^2\left(\sin^{-1}\frac{1}{\sqrt{x}}\right)$
$= \left[\sin\left(\cos^{-1}\frac{1}{3}\right)\right]^2 - \left[\cos\left(\sin^{-1}\frac{1}{\sqrt{3}}\right)\right]^2$
[$x = 3$ বসিয়ে]
$= \left[\sqrt{1 - \left(\frac{1}{3}\right)^2}\right]^2 - \left[\sqrt{1 - \left(\frac{1}{\sqrt{3}}\right)^2}\right]^2$
[সূত্র: $\sin(\cos^{-1} A) = \sqrt{1-A^2}$ এবং $\cos(\sin^{-1} B) = \sqrt{1-B^2}$]
$= \left(1 - \frac{1}{9}\right) - \left(1 - \frac{1}{3}\right)$
[বর্গমূল ও স্কয়ার উঠে গিয়ে]
$= \frac{8}{9} - \frac{2}{3} = \frac{8 - 6}{9} = \frac{2}{9} =$ ডানপক্ষ
$\therefore \sin^2\left(\cos^{-1}\frac{1}{x}\right) - \cos^2\left(\sin^{-1}\frac{1}{\sqrt{x}}\right) = \frac{2}{9}$ (প্রমাণিত)
গ. সমাধান:
প্রদত্ত সমীকরণ: $1 + \sin^2 x - 2\cos^2 x + 3\cos x = 3 - \cos^2 x$
$\Rightarrow 1 + (1 - \cos^2 x) - 2\cos^2 x + 3\cos x - 3 + \cos^2 x = 0$
[$\sin^2 x = 1 - \cos^2 x$ বসিয়ে ও পক্ষান্তর করে]
$\Rightarrow -2\cos^2 x + 3\cos x - 1 = 0$
[যোগ-বিয়োগ করে]
$\Rightarrow 2\cos^2 x - 3\cos x + 1 = 0$
[উভয়পক্ষকে (-1) দ্বারা গুণ করে]
$\Rightarrow 2\cos^2 x - 2\cos x - \cos x + 1 = 0$
[উৎপাদকে বিশ্লেষণ (Middle Term) করে]
$\Rightarrow 2\cos x(\cos x - 1) - 1(\cos x - 1) = 0$
$\Rightarrow (\cos x - 1)(2\cos x - 1) = 0$
হয়, $\cos x - 1 = 0 \Rightarrow \cos x = 1 \Rightarrow x = 2n\pi$ ; যেখানে $n \in \mathbb{Z}$
অথবা, $2\cos x - 1 = 0 \Rightarrow \cos x = \frac{1}{2} \Rightarrow \cos x = \cos\frac{\pi}{3} \Rightarrow x = 2n\pi \pm \frac{\pi}{3}$ ; যেখানে $n \in \mathbb{Z}$
$\therefore$ নির্ণেয় সাধারণ সমাধান: $x = 2n\pi$ অথবা $x = 2n\pi \pm \frac{\pi}{3}$ ; যেখানে $n \in \mathbb{Z}$
প্রশ্ন - ৩

উদ্দীপক: $f(x) = \cos x$, $g(x) = \tan^{-1}x$

ক. দেখাও যে, $g\left(\frac{1}{2}\right) + g\left(\frac{1}{3}\right) = \frac{\pi}{4}$
খ. প্রমাণ কর যে, $2g\left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right) = \cos^{-1}\frac{b+af(\theta)}{a+bf(\theta)}$
গ. সমাধান কর: $\sqrt{3}f(x) + f\left(\frac{\pi}{2}-x\right) = 1$, $-2\pi < x < 2\pi$
৩ নং প্রশ্নের সমাধান:
ক. সমাধান:
উদ্দীপক হতে প্রাপ্ত, $g(x) = \tan^{-1}x$
অতএব, $g\left(\frac{1}{2}\right) = \tan^{-1}\left(\frac{1}{2}\right)$
[$x = \frac{1}{2}$ বসিয়ে]
এবং $g\left(\frac{1}{3}\right) = \tan^{-1}\left(\frac{1}{3}\right)$
[$x = \frac{1}{3}$ বসিয়ে]
বামপক্ষ $= g\left(\frac{1}{2}\right) + g\left(\frac{1}{3}\right)$
$= \tan^{-1}\left(\frac{1}{2}\right) + \tan^{-1}\left(\frac{1}{3}\right)$
$= \tan^{-1}\left( \frac{\frac{1}{2} + \frac{1}{3}}{1 - \frac{1}{2} \cdot \frac{1}{3}} \right)$
[সূত্র: $\tan^{-1}x + \tan^{-1}y = \tan^{-1}\left(\frac{x+y}{1-xy}\right)$ প্রয়োগ করে]
$= \tan^{-1}\left( \frac{\frac{3 + 2}{6}}{1 - \frac{1}{6}} \right)$
[লব ও হরে লসাগু করে]
$= \tan^{-1}\left( \frac{\frac{5}{6}}{\frac{6 - 1}{6}} \right)$
$= \tan^{-1}\left( \frac{\frac{5}{6}}{\frac{5}{6}} \right)$
$= \tan^{-1}(1)$
[লব ও হর কাটাকাটি করে]
$= \tan^{-1}\left(\tan \frac{\pi}{4}\right)$
[যেহেতু $\tan \frac{\pi}{4} = 1$]
$= \frac{\pi}{4} =$ ডানপক্ষ
[যেহেতু $\tan^{-1}(\tan \theta) = \theta$]
$\therefore g\left(\frac{1}{2}\right) + g\left(\frac{1}{3}\right) = \frac{\pi}{4}$ (দেখানো হলো)
খ. সমাধান:
উদ্দীপক হতে প্রাপ্ত, $f(x) = \cos x$ এবং $g(x) = \tan^{-1}x$
অতএব, $f(\theta) = \cos\theta$
বামপক্ষ $= 2g\left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right)$
$= 2\tan^{-1}\left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right)$
[$g(x) = \tan^{-1}x$ বসিয়ে]
আমরা জানি, $2\tan^{-1}x = \cos^{-1}\left(\frac{1-x^2}{1+x^2}\right)$
[ত্রিকোণমিতিক সূত্র]
$= \cos^{-1}\left[ \frac{1 - \left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right)^2}{1 + \left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right)^2} \right]$
$= \cos^{-1}\left[ \frac{1 - \frac{a-b}{a+b}\tan^2\frac{\theta}{2}}{1 + \frac{a-b}{a+b}\tan^2\frac{\theta}{2}} \right]$
[বর্গমূল ও স্কয়ার উঠে গিয়ে]
$= \cos^{-1}\left[ \frac{\frac{(a+b) - (a-b)\tan^2\frac{\theta}{2}}{a+b}}{\frac{(a+b) + (a-b)\tan^2\frac{\theta}{2}}{a+b}} \right]$
[লব ও হরে $(a+b)$ লসাগু করে]
$= \cos^{-1}\left[ \frac{(a+b) - (a-b)\tan^2\frac{\theta}{2}}{(a+b) + (a-b)\tan^2\frac{\theta}{2}} \right]$
[উভয় স্থান থেকে হর $(a+b)$ বাদ দিয়ে]
$= \cos^{-1}\left[ \frac{a + b - a\tan^2\frac{\theta}{2} + b\tan^2\frac{\theta}{2}}{a + b + a\tan^2\frac{\theta}{2} - b\tan^2\frac{\theta}{2}} \right]$
[গুণ করে ব্র্যাকেট তুলে দিয়ে]
$= \cos^{-1}\left[ \frac{b\left(1 + \tan^2\frac{\theta}{2}\right) + a\left(1 - \tan^2\frac{\theta}{2}\right)}{a\left(1 + \tan^2\frac{\theta}{2}\right) + b\left(1 - \tan^2\frac{\theta}{2}\right)} \right]$
[$a$ ও $b$ এর পদসমূহ কমন নিয়ে সাজিয়ে]
$= \cos^{-1}\left[ \frac{b + a \cdot \frac{1 - \tan^2\frac{\theta}{2}}{1 + \tan^2\frac{\theta}{2}}}{a + b \cdot \frac{1 - \tan^2\frac{\theta}{2}}{1 + \tan^2\frac{\theta}{2}}} \right]$
[লব ও হরকে $\left(1 + \tan^2\frac{\theta}{2}\right)$ দিয়ে ভাগ করে]
$= \cos^{-1}\left[ \frac{b + a\cos\theta}{a + b\cos\theta} \right]$
[যেহেতু $\cos\theta = \frac{1 - \tan^2\frac{\theta}{2}}{1 + \tan^2\frac{\theta}{2}}$]
$= \cos^{-1}\left[ \frac{b + af(\theta)}{a + bf(\theta)} \right] =$ ডানপক্ষ
[যেহেতু $f(\theta) = \cos\theta$]
$\therefore 2g\left(\sqrt{\frac{a-b}{a+b}}\tan\frac{\theta}{2}\right) = \cos^{-1}\frac{b+af(\theta)}{a+bf(\theta)}$ (প্রমাণিত)
গ. সমাধান:
উদ্দীপক অনুযায়ী, $f(x) = \cos x$
প্রদত্ত সমীকরণ: $\sqrt{3}f(x) + f\left(\frac{\pi}{2}-x\right) = 1$
$\Rightarrow \sqrt{3}\cos x + \cos\left(\frac{\pi}{2}-x\right) = 1$
[$f(x)$ এর মান বসিয়ে]
$\Rightarrow \sqrt{3}\cos x + \sin x = 1$
[যেহেতু $\cos\left(\frac{\pi}{2}-x\right) = \sin x$]
সহগদ্বয়ের বর্গের সমষ্টির বর্গমূল $= \sqrt{(\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = \sqrt{4} = 2$
সমীকরণের উভয়পক্ষকে $2$ দ্বারা ভাগ করে পাই:
$\Rightarrow \frac{\sqrt{3}}{2}\cos x + \frac{1}{2}\sin x = \frac{1}{2}$
$\Rightarrow \cos x \cdot \cos\frac{\pi}{6} + \sin x \cdot \sin\frac{\pi}{6} = \frac{1}{2}$
[যেহেতু $\cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$ এবং $\sin\frac{\pi}{6} = \frac{1}{2}$]
$\Rightarrow \cos\left(x - \frac{\pi}{6}\right) = \cos\frac{\pi}{3}$
[সূত্র: $\cos A \cos B + \sin A \sin B = \cos(A-B)$]
আমরা জানি, $\cos\theta = \cos\alpha$ হলে সাধারণ সমাধান $\theta = 2n\pi \pm \alpha$ ; যেখানে $n \in \mathbb{Z}$
$\Rightarrow x - \frac{\pi}{6} = 2n\pi \pm \frac{\pi}{3} \Rightarrow x = 2n\pi \pm \frac{\pi}{3} + \frac{\pi}{6}$
ধনাত্মক (+) চিহ্ন নিয়ে: $x = 2n\pi + \frac{\pi}{3} + \frac{\pi}{6} = 2n\pi + \frac{\pi}{2}$
ঋণাত্মক (-) চিহ্ন নিয়ে: $x = 2n\pi - \frac{\pi}{3} + \frac{\pi}{6} = 2n\pi - \frac{\pi}{6}$
এখন, প্রদত্ত সীমার মধ্যে ($-2\pi < x < 2\pi$) $n$ এর মান বসাই:
• $n = 0$ হলে: $x = \frac{\pi}{2}$ (গ্রহণযোগ্য), $x = -\frac{\pi}{6}$ (গ্রহণযোগ্য)
• $n = 1$ হলে: $x = \frac{5\pi}{2}$ (সীমার বাইরে), $x = \frac{11\pi}{6}$ (গ্রহণযোগ্য)
• $n = -1$ হলে: $x = -\frac{3\pi}{2}$ (গ্রহণযোগ্য), $x = -\frac{13\pi}{6}$ (সীমার বাইরে)
$\therefore$ নির্ণেয় সমাধান: $x = -\frac{3\pi}{2}, -\frac{\pi}{6}, \frac{\pi}{2}, \frac{11\pi}{6}$
প্রশ্ন - ৪

উদ্দীপক: $f(x) = \sin^{-1}x$ একটি বিপরীত ত্রিকোণমিতিক ফাংশন।

ক. $f(x) = \tan^{-1}a$ হলে, $a = ?$
খ. $f(x) + f(y) = \frac{\pi}{2}$ হলে, দেখাও যে, $x^2 + y^2 = 1$
গ. $f(x) + f(y) + f(z) = \pi$ হলে, প্রমাণ কর যে, $x\sqrt{1-x^2} + y\sqrt{1-y^2} + z\sqrt{1-z^2} = 2xyz$
৪ নং প্রশ্নের সমাধান:
ক. সমাধান:
উদ্দীপক হতে প্রাপ্ত, $f(x) = \sin^{-1}x$
প্রশ্নমতে, $f(x) = \tan^{-1}a \Rightarrow \sin^{-1}x = \tan^{-1}a$
ধরি, $\theta = \sin^{-1}x \Rightarrow \sin\theta = x = \frac{x}{1}$
সমকোণী ত্রিভুজ হতে: লম্ব $= x$, অতিভুজ $= 1$, ভূমি $= \sqrt{1 - x^2}$
আমরা জানি, $\tan\theta = \frac{\text{লম্ব}}{\text{ভূমি}} = \frac{x}{\sqrt{1-x^2}} \Rightarrow \theta = \tan^{-1}\left(\frac{x}{\sqrt{1-x^2}}\right)$
অতএব, $\sin^{-1}x = \tan^{-1}\left(\frac{x}{\sqrt{1-x^2}}\right)$
সমীকরণে মান বসিয়ে পাই: $\tan^{-1}\left(\frac{x}{\sqrt{1-x^2}}\right) = \tan^{-1}a$
$\therefore a = \frac{x}{\sqrt{1-x^2}}$
খ. সমাধান:
দেওয়া আছে, $f(x) + f(y) = \frac{\pi}{2} \Rightarrow \sin^{-1}x + \sin^{-1}y = \frac{\pi}{2}$
$\Rightarrow \sin^{-1}x = \frac{\pi}{2} - \sin^{-1}y$
[পক্ষান্তর করে]
$\Rightarrow x = \sin\left(\frac{\pi}{2} - \sin^{-1}y\right)$
[উভয়পাশে $\sin$ নিয়ে]
$\Rightarrow x = \cos(\sin^{-1}y)$
[যেহেতু $\sin\left(\frac{\pi}{2} - \theta\right) = \cos\theta$]
$\Rightarrow x = \cos\left(\cos^{-1}\sqrt{1-y^2}\right)$
[যেহেতু $\sin^{-1}y = \cos^{-1}\sqrt{1-y^2}$]
$\Rightarrow x = \sqrt{1-y^2}$
[যেহেতু $\cos(\cos^{-1}\theta) = \theta$]
$\Rightarrow x^2 = 1 - y^2$
[বর্গ করে]
$\therefore x^2 + y^2 = 1$ (দেখানো হলো)
গ. সমাধান:
দেওয়া আছে, $f(x) + f(y) + f(z) = \pi \Rightarrow \sin^{-1}x + \sin^{-1}y + \sin^{-1}z = \pi$
ধরি, $\sin^{-1}x = A \Rightarrow x = \sin A$, $\sin^{-1}y = B \Rightarrow y = \sin B$, $\sin^{-1}z = C \Rightarrow z = \sin C$
তাহলে, $A + B + C = \pi$ এবং $\cos A = \sqrt{1-x^2}, \cos B = \sqrt{1-y^2}, \cos C = \sqrt{1-z^2}$
বামপক্ষ $= x\sqrt{1-x^2} + y\sqrt{1-y^2} + z\sqrt{1-z^2}$
$= \sin A \cos A + \sin B \cos B + \sin C \cos C$
$= \frac{1}{2} \cdot [2\sin A \cos A + 2\sin B \cos B + 2\sin C \cos C]$
[$2$ দিয়ে গুণ ও ভাগ করে]
$= \frac{1}{2} [\sin 2A + \sin 2B + \sin 2C]$
[সূত্র: $2\sin\theta\cos\theta = \sin 2\theta$]
$= \frac{1}{2} [2\sin(A+B)\cos(A-B) + 2\sin C \cos C]$
[প্রথম দুটি পদে $\sin C + \sin D$ এর সূত্র প্রয়োগ করে]
$= \frac{1}{2} [2\sin C \cos(A-B) + 2\sin C \cos C]$
[যেহেতু $\sin(A+B) = \sin(\pi - C) = \sin C$]
$= \sin C [\cos(A-B) + \cos(\pi - (A+B))]$
[$2\sin C$ কমন নিয়ে ও $C = \pi - (A+B)$ বসিয়ে]
$= \sin C [\cos(A-B) - \cos(A+B)]$
[যেহেতু $\cos(\pi - \theta) = -\cos\theta$]
$= \sin C [2\sin A \sin B] = 2\sin A \sin B \sin C = 2xyz =$ ডানপক্ষ
$\therefore x\sqrt{1-x^2} + y\sqrt{1-y^2} + z\sqrt{1-z^2} = 2xyz$ (প্রমাণিত)
প্রশ্ন - ৫

উদ্দীপক: $f(x) = \cos x$, $A = \sec^{-1}\frac{2}{x}$, $B = \sec^{-1}\frac{3}{y}$

ক. সমাধান কর: $\tan 2x - \tan x = 0$
খ. সমাধান কর: $\sqrt{2}f(x) - \sqrt{2}f\left(\frac{\pi}{2}-x\right) = 1$ ; যখন $-\pi < x < \pi$
গ. দেখাও যে, $A + B = \frac{\pi}{2}$ সমীকরণটি একটি উপবৃত্ত নির্দেশ করে।
৫ নং প্রশ্নের সমাধান:
ক. সমাধান:
প্রদত্ত সমীকরণ: $\tan 2x - \tan x = 0$
$\Rightarrow \frac{\sin 2x}{\cos 2x} - \frac{\sin x}{\cos x} = 0 \Rightarrow \frac{\sin 2x \cos x - \cos 2x \sin x}{\cos 2x \cos x} = 0$
$\Rightarrow \sin 2x \cos x - \cos 2x \sin x = 0$
$\Rightarrow \sin(2x - x) = 0 \Rightarrow \sin x = 0$
[সূত্র: $\sin A \cos B - \cos A \sin B = \sin(A-B)$]
আমরা জানি, $\sin\theta = 0$ হলে সাধারণ সমাধান $\theta = n\pi$ ; যেখানে $n \in \mathbb{Z}$
$\therefore$ নির্ণেয় সমাধান: $x = n\pi$ ; যেখানে $n \in \mathbb{Z}$
খ. সমাধান:
উদ্দীপক অনুযায়ী, $f(x) = \cos x$
প্রদত্ত সমীকরণ: $\sqrt{2}f(x) - \sqrt{2}f\left(\frac{\pi}{2}-x\right) = 1 \Rightarrow \sqrt{2}\cos x - \sqrt{2}\sin x = 1$
$\Rightarrow \cos x - \sin x = \frac{1}{\sqrt{2}}$
[উভয়পক্ষকে $\sqrt{2}$ দ্বারা ভাগ করে]
উভয়পক্ষকে আবার $\sqrt{2}$ দ্বারা ভাগ করে পাই:
$\Rightarrow \frac{1}{\sqrt{2}}\cos x - \frac{1}{\sqrt{2}}\sin x = \frac{1}{2}$
$\Rightarrow \cos x \cdot \cos\frac{\pi}{4} - \sin x \cdot \sin\frac{\pi}{4} = \frac{1}{2}$
$\Rightarrow \cos\left(x + \frac{\pi}{4}\right) = \cos\frac{\pi}{3}$
[সূত্র: $\cos A \cos B - \sin A \sin B = \cos(A+B)$]
$\Rightarrow x + \frac{\pi}{4} = 2n\pi \pm \frac{\pi}{3} \Rightarrow x = 2n\pi \pm \frac{\pi}{3} - \frac{\pi}{4}$
ধনাত্মক (+) চিহ্ন নিয়ে: $x = 2n\pi + \frac{\pi}{12}$
ঋণাত্মক (-) চিহ্ন নিয়ে: $x = 2n\pi - \frac{7\pi}{12}$
এখন, প্রদত্ত সীমার মধ্যে ($-\pi < x < \pi$) $n$ এর মান বসাই:
• $n = 0$ হলে: $x = \frac{\pi}{12}$ (গ্রহণযোগ্য), $x = -\frac{7\pi}{12}$ (গ্রহণযোগ্য)
• $n = 1, -1$ এর ক্ষেত্রে প্রাপ্ত মানগুলো $-\pi < x < \pi$ সীমার বাইরে চলে যায়।
$\therefore$ নির্ণেয় সমাধান: $x = \frac{\pi}{12}, -\frac{7\pi}{12}$
গ. সমাধান:
উদ্দীপক হতে: $A = \sec^{-1}\frac{2}{x} = \cos^{-1}\left(\frac{x}{2}\right)$ এবং $B = \sec^{-1}\frac{3}{y} = \cos^{-1}\left(\frac{y}{3}\right)$
দেওয়া আছে, $A + B = \frac{\pi}{2} \Rightarrow \cos^{-1}\left(\frac{x}{2}\right) + \cos^{-1}\left(\frac{y}{3}\right) = \frac{\pi}{2}$
$\Rightarrow \cos^{-1}\left(\frac{x}{2}\right) = \frac{\pi}{2} - \cos^{-1}\left(\frac{y}{3}\right)$
[পক্ষান্তর করে]
$\Rightarrow \frac{x}{2} = \cos\left(\frac{\pi}{2} - \cos^{-1}\left(\frac{y}{3}\right)\right)$
[উভয়পাশে $\cos$ নিয়ে]
$\Rightarrow \frac{x}{2} = \sin\left(\cos^{-1}\left(\frac{y}{3}\right)\right)$
[যেহেতু $\cos\left(\frac{\pi}{2} - \theta\right) = \sin\theta$]
$\Rightarrow \frac{x}{2} = \sin\left(\sin^{-1}\sqrt{1 - \frac{y^2}{9}}\right)$
[যেহেতু $\cos^{-1}\left(\frac{y}{3}\right) = \sin^{-1}\sqrt{1 - \frac{y^2}{9}}$]
$\Rightarrow \frac{x}{2} = \sqrt{1 - \frac{y^2}{9}}$
$\Rightarrow \left(\frac{x}{2}\right)^2 = 1 - \frac{y^2}{9}$
[উভয়পক্ষে বর্গ করে]
$\Rightarrow \frac{x^2}{4} + \frac{y^2}{9} = 1 \Rightarrow \frac{x^2}{2^2} + \frac{y^2}{3^2} = 1$
আমরা জানি, $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ হলো একটি **উপবৃত্তের (Ellipse)** আদর্শ সমীকরণ।
$\therefore A + B = \frac{\pi}{2}$ সমীকরণটি একটি উপবৃত্ত প্রকাশ করে। (দেখানো হলো)
